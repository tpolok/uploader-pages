What Uploader is

Uploader is a personal, self-hosted application run locally by its owner to upload and schedule the owner's own videos to their own YouTube channel.

Data accessed

When the owner connects their Google account, Uploader requests these scopes:

  • youtube.upload – to upload videos to the connected channel;
  • youtube.readonly – to read basic channel information (channel ID and name) and to check that an uploaded video still exists.

How data is used and stored

  • OAuth tokens (access and refresh tokens) are stored encrypted (AES-256-GCM) in a local database on the owner's own computer.
  • Videos, captions and titles are stored locally and deleted once publication is finished.
  • Data is used only to perform the uploads requested by the owner.

Sharing

Uploader does not sell, share, transfer or disclose any user data to third parties, and does not use it for advertising. Data is only exchanged with Google's YouTube API in order to perform the requested uploads.

Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local database removes all stored tokens.

YouTube Terms

Uploader uses YouTube API Services. By using it you agree to the YouTube Terms of Service and the Google Privacy Policy.

Français

Ce qu'est Uploader

Uploader est une application personnelle, auto-hébergée, exécutée en local par son propriétaire pour envoyer et programmer ses propres vidéos sur sa propre chaîne YouTube.

Données consultées

Lorsque le propriétaire connecte son compte Google, Uploader demande les autorisations youtube.upload (envoyer des vidéos) et youtube.readonly (lire l'identifiant et le nom de la chaîne, et vérifier qu'une vidéo envoyée existe toujours).

Utilisation et stockage

Les tokens OAuth sont stockés chiffrés (AES-256-GCM) dans une base de données locale, sur l'ordinateur du propriétaire. Les vidéos, descriptions et titres sont stockés localement et supprimés une fois la publication terminée. Les données servent uniquement à réaliser les envois demandés par le propriétaire.

Partage

Uploader ne vend, ne partage et ne transmet aucune donnée à des tiers, et ne l'utilise pas à des fins publicitaires. Les seuls échanges se font avec l'API YouTube de Google pour effectuer les envois demandés. L'utilisation des informations reçues des API Google respecte la Google API Services User Data Policy, y compris les exigences d'utilisation limitée.

Révocation et suppression

L'accès peut être révoqué à tout moment sur myaccount.google.com/permissions. Supprimer la base de données locale efface tous les tokens.
